== Description ==
Genera artículos optimizados para buscadores con texto e imágenes de Gemini en WordPress.

== Installation ==
1. Sube el plugin a /wp-content/plugins/
2. Actívalo
3. Ve a AIBlogger -> Configuración

== Actualizaciones ==
WordPress consulta el manifiesto de AIBlogger en https://repo.gorvet.com/updates/aiblogger/info.json.
Activa las actualizaciones automáticas en la fila de AIBlogger de la pantalla Plugins.
